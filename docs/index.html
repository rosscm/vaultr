Why I Built Vaultr

I spend way too much time checking the same card searches.

I collect the same way a lot of people do: a few cards I'm actively hunting for, a longer wishlist than I'd probably admit to, and a bunch of searches I mean to check again later. Vaultr started as a way to make that easier without turning collecting into homework.

Chase-specific

It starts from the cards you actually care about instead of dropping you into another giant marketplace feed.

Private by default

Sightings stay private, so you can check them on your own time without turning a server channel into listing spam.

It learns your taste

Weekly Shelf gets more personal as your Vault and feedback build up real taste profile memory over time.

Built for how collectors actually check in

Discord is still the core home for sightings and server interaction, and a broader web experience is planned as beta expands.
